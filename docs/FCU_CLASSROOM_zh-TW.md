# FCU C 課堂：教師與代理人操作交接

本頁說明如何從空白班級建立可供學生使用的 C 練習及限時測驗。教師可在同一台伺服器建立多個班級；每班有自己的名冊、題目、開放時間與成績。部署、備份與主機設定由[後端部署文件](https://github.com/EthanYangTW/OnlineJudge/blob/master/fcu/README_zh-TW.md)處理。

## 入口與事前檢查

- 學生入口：`http://<校內伺服器位址>/classroom`，若學校已設定 HTTPS，也可用對應的 `https://` 網址。伺服器本機驗收可用 `http://127.0.0.1:5482/classroom`。
- 教師入口：相同主機的 `/admin/classroom`；本機驗收可用 `http://127.0.0.1:5482/admin/classroom`。
- 教師帳號由伺服器環境變數 `FCU_TEACHER_USER`、`FCU_TEACHER_PASSWORD` 初始化。請勿把教師密碼寫入前端、CSV、Git 或本文件。
- 先確認 HTTPS、PostgreSQL、Redis、QDU JudgeServer 與獨立的 C 語法檢查容器都正常。若語法服務暫停，學生仍可送出程式給正式評測；「檢查語法」會顯示暫時無法使用。
- 在兩台不同的校內學生電腦測試登入，於教師「Students」表格確認其 `Locked IP` 不同，再啟用正式測驗。若兩人顯示同一個代理伺服器位址，先修正反向代理的真實來源 IP 設定。

## 1. 建立課堂與匯入學生

1. 教師登入 `/admin/`，左側開啟 **FCU Classroom**，按 **New class**。填入只含小寫英數及連字號的 Class ID（例如 `fcu-c-a`）和班級名稱。另一班再按一次 **New class** 建立另一個代碼；頁面頂端的班級選單可切換管理對象。
2. 選擇課堂的 **Students** 分頁，按 **Import CSV**。CSV 必須是 UTF-8，第一列欄名固定為 `login,name,class,password`。
3. `login` 填學號；若要求初始帳密為「學號：學號」，`password` 也填同一學號。例如以下是假資料，不能當正式名冊：

   ```csv
   login,name,class,password
   D9990001,測試學生,甲班,D9990001
   D9990002,測試學生,甲班,D9990002
   ```

4. 上傳 CSV 或貼入文字後按 **Import**，確認學生清單、人數及姓名正確，沒有 `???`。重匯同一份、密碼未變的名冊會保留既有登入與 IP 綁定；某筆密碼若改變，該學生的工作階段與 IP 綁定會清除。正式考試期間勿直接重匯整份名冊。
5. 學號作密碼可被猜到。校內驗收可依此設定；正式評量若允許，請改用每人不同的隨機密碼並安全地交付學生。

名冊原檔、學號密碼對照表、真實姓名資料都留在教師管理的私有位置。**不可提交到 Git、放進前端 `dist/`，或貼到公開 issue。**伺服器只保存密碼雜湊；網頁不會收到學生密碼。

目前同一學號只能匯入**一個**班級；若另一班的名冊含相同學號，後端會拒絕該筆，避免跨班帳號混用。請先依班級切分名冊並檢查學號不重複。每次匯入上限 500 人、CSV 上限 256 KiB。

### 指派助教

班級建立者可在 **Assistants** 分頁按 **Add assistant**，輸入助教登入名稱、姓名及至少 12 字元的獨立密碼。系統建立的是**一般使用者帳號加上所選班級的助教權限**，不會授予全站管理員身分；密碼只在建立時傳到伺服器，之後僅保存雜湊，畫面不再顯示。助教從 `/admin/login` 登入後會直接進入 `/admin/classroom`，只能管理被指派的班級。助教可查看該班成績及提交、管理名冊、IP 規則、測驗與選擇題；新增原生 QDU C 題目須由班級建立者操作。

同一位教師若有多個班級，可在另一班的 **Add assistant** 勾選「Assign an assistant account already used in another class I own」，填相同登入名稱指派現有助教，不需重設密碼。只有班級建立者或全站管理員可指派、列出及移除助教；其他班的教師不能接管該帳號。移除助教後，該班的管理權會立即失效。請不要把學生帳號提升為助教，系統也會拒絕直接使用已有學生登入名稱。

## 2. IP 綁定

**Students** 的 **One IP per student** 開關控制整班。每位學生首次登入後綁定當時的用戶端 IP；同一帳號從其他 IP 登入會被拒絕。

- 個別暫停：該學生列的 **IP rule** 切到 Off。
- 個別重新綁定：按 **Reset IP**；原連線會被登出，下一次登入綁定新 IP。
- 全班重新綁定：按 **Reset all IP locks**。此操作會登出學生，應在考前或換教室時執行。
- 全班暫停：關閉 **One IP per student**。恢復前再次確認反向代理傳入真正學生 IP。

IP 綁定是管理措施，不能替代網路隔離。考場仍須阻止學生設備連到公網，並限制學生只可存取考試伺服器。

## 3. 建立練習或限時測驗

1. 開啟 **Quizzes**，按 **New quiz**，輸入 Quiz ID 與名稱。
2. 選 **Practice** 或 **Exam**。兩者互相獨立；學生可以自由選任何已開放測驗，不必先完成上一份。
3. 設定 **Starts**；Exam 必須設定 **Closes**。期限一到，伺服器拒絕新的答案、程式與草稿更新。學生端倒數使用伺服器時間校正。
4. 先保留 **Publish to students** 未勾選，建好題目並驗收後，再於 **Quiz settings** 發布。需要立即停止時，取消 **Published** 或把截止時間改為已過時間。
5. 截止後學生仍可看自己的分數、提交紀錄與保存的程式；題目不再接受作答。

若要快速加入既有 FCU 題庫，可在建班後依[舊 C 題庫匯入流程](https://github.com/EthanYangTW/OnlineJudge/blob/master/fcu/IMPORT_C_BANK_zh-TW.md)建立 6 份**未發布**練習：20 題 C、15 題選擇題。匯入器需由部署代理在後端容器執行；教師再逐份檢查與發布。對不同班級分別執行一次，各班之後可獨立修改分數與時段。

教授於 2026-11-05 提供的 8 題 C 教學範例，已於 2026-11-06 匯入 Windows 主機的 `fcu-c-2026` 班級，仍為**未發布**練習。教師先在 **Quizzes** 檢查英文題面、每題配分、輸入輸出格式與[待確認事項](https://github.com/EthanYangTW/OnlineJudge/blob/master/fcu/PROFESSOR_C_DRAFTS_zh-TW.md)，再於 **Quiz settings** 發布。參考程式不會進入學生題面；62 組私人測資不在公開儲存庫。要求學生「必須寫函式」仍需人工檢查程式碼。期中考若採用這些題，須另建限時 **Exam** 題組、設定截止時間並驗收。

若由代理人以檔案自動建立班級與學生，可依[部署文件的 `provision_fcu_class` 流程](https://github.com/EthanYangTW/OnlineJudge/blob/master/fcu/README_zh-TW.md#教師建立課堂與測驗)在後端容器匯入私有 CSV；該流程與教師頁的匯入使用相同規則。代理人應先在測試班級確認學號、中文姓名與分數，再開放正式測驗。

## 4. 加入選擇題

在測驗列按 **Open** → **New question** → Type 選 **Multiple choice**。填 Question ID、標題、題幹、分數及排序。**Choices** 每行一個選項，可輸入 A、B、C、D 四項；**Correct choice** 用 1 表示第一行、2 表示第二行。學生畫面只收到選項，不會收到正解索引。Exam 選擇題每人每題只允許一次提交；Practice 可重試。

## 5. 加入 C 程式題與測資

1. 先在測驗的題目區按 **Create a C problem in this quiz**，進入 QDU 原生題目編輯器。這會把題目建在該測驗對應的 QDU contest 內。
2. 題型選 **OI**，語言**只勾 C**，I/O 選 **Standard IO**。填題目敘述、輸入/輸出說明、至少一組公開範例及必要 tag。不要加入解答、答題提示或隱藏測資到公開說明或程式模板。
3. 準備測資 ZIP，ZIP 根目錄放連續編號的配對檔：`1.in`、`1.out`、`2.in`、`2.out`，依序延伸，不留號碼缺口。每個 `.in` 是標準輸入，每個 `.out` 是正確標準輸出。檢查空白、換行、邊界值與錯誤路徑；測資不能只重複公開範例。
4. 上傳 ZIP 後，為每組測資設定正整數 **Score**，再儲存題目。QDU 題目列表的數字 **ID** 是內部 ID；旁邊的 **Display ID** 是另一個識別碼。
5. 回 **FCU Classroom** → 該測驗 **Open** → **New question**，Type 選 **C lab**，輸入自訂分數及上一步的數字 **QDU C problem ID**，儲存。後端會要求該題屬於此測驗、採 OI、只允許 C，且已有計分測資。

學生的 C 題得分是 `課堂題目分數 × QDU 測資得分 ÷ QDU 測資總分`，結果取整數；教師可單獨設定每題滿分。已有學生提交後，QDU 測資、時限、語言、模板與測資分數不可更動；課堂配分仍可調整，系統會重算所有既有提交的分數。要改測資或評測規則時，建立新的題目 ID 並重新發布。

學生工作區採題目／編輯器左右分欄，提供深色與淺色模式、C 語法著色、關鍵字與常用函式補全。輸入時會立即顯示本機 C 語言候選字，按 **Tab** 選取目前候選項；沒有候選清單時 Tab 保持一般縮排，亦可按 **Ctrl／Cmd + Space** 主動叫出補全。補全僅有語言關鍵字與標準函式，沒有題目答案或網路建議。下方 **測試資料** 可選公開範例或自行填入標準輸入；按 **Run** 會在獨立沙箱編譯並執行這一組輸入，顯示輸出、編譯或執行錯誤與耗時，**不計分**。按 **檢查語法** 只編譯、不執行、不計分。這兩種操作都不讀隱藏測資。

按 **Submit** 才會交由正式 QDU JudgeServer 用隱藏測資評分。每次正式提交的原始程式碼、結果與得分會保存；編輯中草稿也會自動存入伺服器。學生可在 **我的提交** 看自己的歷史和程式，不能看其他人的程式、正解或隱藏輸入輸出。題目的公開範例只用於練習說明；教師需另備覆蓋邊界條件的私人測資。

## 6. 驗收與成績

1. 用測試學號開 `/classroom`，只輸入學號與密碼；系統會依帳號的唯一班級自動進入課堂，不要求課堂代碼。確認只能看到該班已發布且開始的 Practice/Exam；每題可自由切換，學生頁不以題號作主要標題。
2. 在 C 題輸入不完整程式，按 **檢查語法**，應看到行號與錯誤；再輸入可編譯程式，於 **測試資料** 改成自訂輸入按 **Run**，確認輸出沒有改變成績。最後按 **Submit**，確認正式評測結果、原始程式與得分保存。切換題目或重新整理，草稿應從伺服器恢復。
3. 測試選擇題錯誤及正確答案、部分通過的 C 測資、編譯失敗、逾時，以及截止後拒絕提交。用第二台學生電腦確認 IP 綁定和看不到第一人的成績與程式。
4. 在 **Practice** 的課堂首頁看 **練習動態**、**練習排行榜**；登入後頂部導覽的 **排行榜** 可直接回到目前班級的練習排行榜。進入單份練習也可看該份的 **狀態**、**排行榜**。同班學生只會看到姓名、分數與提交狀態，**看不到彼此程式碼**。Exam 不提供學生互看的排行或動態。教師在 **Scores** 選「全部」或單一測驗，查看全班排行與每人最高分；按學生列的 **Code** 檢視提交紀錄與程式；**Export CSV** 下載成績。CSV 含學號與姓名，應放在私有位置。
5. 備份 PostgreSQL 資料與伺服器上的測資目錄。重新部署前先驗證備份可還原，勿把備份放進 Git。

學生不能自行註冊。班級建立者可指派班級助教；教師與其指派的助教可管理該班測驗、分數與名冊，其他學生無法操作。新增全站帳號或原生 QDU C 題目仍由具備相應管理權的教師執行；後端會逐項檢查權限。
